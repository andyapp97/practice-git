# Rules for this repo

- Never commit to main. Every change goes on a new branch and through a pull request.
- Commit messages use a conventional prefix: feat, fix, docs, chore, test.
- The word TODO is not allowed in any file. CI fails on it.
- Do not add dependencies or new tools without asking first.
- Every pull request description has three sections: "What was asked", "What was built", and "Deviation and why".
